# Demo Project - 7-Segment LCD Meter Synthetic Editor

An interactive web-based 7-Segment LCD Meter Synthetic Editor.

## Features
- Real-time 7-segment digital display rendering
- Configurable LCD parameters (digits, decimals, styles, colors)
- Responsive dark-themed UI
- Ready to deploy directly to Vercel or GitHub Pages

## Deployment
This project is configured to run out of the box on [Vercel](https://vercel.com).
